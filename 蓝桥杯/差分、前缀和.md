## 一维前缀和和差分
前缀和
```cpp
s[i] = s[i - 1] + a[i];
```
### 一维差分
![[Pasted image 20260517223119.png]]
```cpp
// 核心操作，在[l, r]上每个加c
void insert(int l, int r, int c) {
	b[l] += c;
	b[r + 1] -= c;
}
```
## 二维前缀和 && 差分
前缀和
```cpp
s[i][j] = s[i][j - 1] + s[i - 1][j] - s[i - 1][j - 1] + a[i][j];
```
### 二维差分
![[Pasted image 20260517231627.png]]
```cpp
// 核心操作，在(x1, y1)到(x2, y2)每个加c
void (int x1, int y1, int x2, int y2, int c) {
	b[x1][y1] += c;
	b[x1][y2 + 1] -= c;
	b[x2 + 1][y1] -= c;
	b[x2 + 1][y2 + 1] += c;
}
```
